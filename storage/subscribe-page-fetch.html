The security key is a physical device, in the form of a USB key, that guarantees access and continuity of use of your development tools.

For ecological reasons, we have chosen to reuse the device we used to call "dongle" and transform it into a security key.

If you have WINDEV Suite, WINDEV, WEBDEV or WINDEV Mobile subscription, you probably already have a key associated with these products. Some of these keys may already have been downgraded, while others may still need to be migrated.

It is possible to convert a dongle into a security key in the following 2 cases:

  • you are using versions 28, 2024 or 2025.
  • you are using a downgraded dongle.

Once converted, this key becomes your official security key.

Important: This process is irreversible.

This security key is very important and it is strongly recommended to keep it in a secure place, such as a safe.

The security key meets client needs related to:

  • Business Recovery Plan (BRP)
  • Information System Security Policy (PSSI)

It is part of a global strategy based on quality and service continuity, complementing the subscription model.

No organization is totally immune to exceptional situations such as:

  • cyber attack
  • general failure
  • network failure
  • piracy
  • infrastructure failure
  • geopolitical context or major crisis

Some users also wonder what would happen if PC SOFT ran into difficulties or went bankrupt. In this respect, PC SOFT is part of the CSI group, one of the world's largest software publishing groups, which guarantees a high degree of stability and continuity.

The security key provides additional security. In the event of a major breakdown, simply use the key and continue working. You can:
  • maintain existing projects
  • start new development projects

If you activate the security key option while your subscription is active, you can update the security key to the the latest version supported in your subscription.

When you cancel your subscription:
  • the key remains functional
  • it is simply frozen in the latest version of your subscription, minimum version 2026 of June (provided you have previously activated the security key and carried out updates during the subscription period).
You can therefore continue to use this version to:
  • maintain existing projects
  • continue your development projects in this version

As soon as you activate the security key option, we recommend that you load the version corresponding to your subscription onto the key.

Then, as long as your subscription is active and the security key option is activated, you can update the key at any moment.

If you cancel your subscription, the key will remain in the latest version installed.

Please note that you must update the security key to the latest version every year. You can do this at any time.

The security key is not intended as an execution tool (see "Why the security key was introduced"), even though it can be used to:

  • Open projects
  • Create or edit code in an existing project
  • Compile
  • Deploy
  • Use the tools accessible from the editor menus
  • Create new projects

The security key provides access to:

  • versions 23 and earlier
  • to versions 2026 (from June) and higher, until you stop your subscription

Whether you activate security key now or later, access is supported from version 2026.

For versions 24 to 2025, access to projects still depends on the subscription.

The security key should be kept in a secure place.

In the following cases:

  • loss
  • theft
